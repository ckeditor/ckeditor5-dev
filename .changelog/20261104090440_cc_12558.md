The manual test server now picks up edits to inline `<style>` elements in manual test HTML files. Before, the bundled development server kept serving the inline styles from the moment it started while the rest of the page updated, so a correct CSS change could look broken until the server was restarted. Inline module scripts and `style` attributes that Vite processes are refreshed the same way.
