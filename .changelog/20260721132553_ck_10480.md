Translation files generated for Simplified and Traditional Chinese are no longer ambiguous.

* `zh_CN` (Simplified Chinese) now generates the `zh-hans.po` file instead of `zh-cn.po`.
* `zh_TW` (Traditional Chinese) now generates the `zh-hant.po` file instead of `zh.po`.
