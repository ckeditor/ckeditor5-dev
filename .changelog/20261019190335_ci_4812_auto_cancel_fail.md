The `ckeditor5-dev-ci-circle-disable-auto-cancel-builds` and `ckeditor5-dev-ci-circle-enable-auto-cancel-builds` scripts now fail with a clear error message when CircleCI rejects the request with a non-2xx response. Previously, the scripts reported success even when the "Auto-cancel redundant workflows" option was not updated, which allowed a new push to cancel a running release workflow.
