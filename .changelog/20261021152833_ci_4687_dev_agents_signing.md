scope:
  - ckeditor5-dev-agents
see:
  - https://github.com/ckeditor/ckeditor5-internal/issues/4687

Published runs now commit with the git configuration of the checkout: its author and its signing setup, for example the bot configured in CI. Previously, they always used the `CKEditor AI Tasks <ai-tasks@users.noreply.github.com>` author, which GitHub attributes to an unrelated account, and never signed the commits. `AI_TASKS_GIT_NAME` and `AI_TASKS_GIT_EMAIL` still override the author. Publishing fails with a clear message when no author is configured.
