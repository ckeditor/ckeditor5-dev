Published runs now commit with the git configuration of the checkout: its author and its signing setup, for example the bot configured in CI. `AI_TASKS_GIT_NAME` and `AI_TASKS_GIT_EMAIL` still override the author. Publishing fails with a clear message when no author is configured.
