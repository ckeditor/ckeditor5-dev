The `reassignNpmTags()` and `removeNpmTags()` tasks now work on Windows. Before, they put the values passed to npm, such as package names and versions, in single quotes, which only POSIX shells remove. On Windows, npm got the quotes as a part of the values: it could not find scoped packages, and `removeNpmTags()` reported unscoped packages as skipped while their tag stayed in place.

The tasks now pass the values to npm without quotes and validate them first. They throw an error before running npm when a package name or the npm tag contains characters other than letters, digits, `.`, `_`, and `-` (a package name may also have a scope), or when the version is not valid.
