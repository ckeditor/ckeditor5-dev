Introduced the `@ckeditor/ckeditor5-dev-agents` package. It runs recurring AI agent tasks against a repository and delivers the results as a pull request. A task judges the units it defines, skips the units whose content has not changed since the last run, and can fix what it finds. A human reviews the findings and the fixes in the pull request.
